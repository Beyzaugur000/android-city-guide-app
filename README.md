# Android City Guide App

A city and travel guide mobile application developed using Java and Android Studio.

## Features
- City listing system
- Detail pages for locations
- RecyclerView structure
- Fragment-based navigation
- Interactive mobile interface
- Modern Android UI design

## Technologies
- Java
- Android Studio
- XML
- Gradle

## Project Structure

app/src/main/
- java/
- res/
- AndroidManifest.xml

## Purpose of the Project

This project was developed to improve Android mobile application development and user interface design skills.
